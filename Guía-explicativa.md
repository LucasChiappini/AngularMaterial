## ¿Qué es Angular Material y cómo funciona?

### ¿Qué es Angular Material?

Angular Material es la **biblioteca de componentes de interfaz de usuario (UI)** oficial desarrollada por el equipo de Angular. Implementa la especificación de **Material Design** de Google.

Proporciona componentes prediseñados, accesibles, adaptables y probados (como botones, tarjetas, tablas, formularios, modales y barras de navegación), evitando tener que escribir estilos CSS desde cero.

### ¿Cómo se instala en un proyecto de Angular?

Se instala mediante la herramienta de comandos de Angular (CLI) ejecutando:

```bash
ng add @angular/material
```
