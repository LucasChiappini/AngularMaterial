# UserManager - Angular Material Demo

Aplicación base desarrollada en Angular con Angular Material para la presentación práctica del sistema de componentes web. 

El proyecto está dividido en tres secciones funcionales interconectadas:
1. **Home (`/home`):** Pantalla principal de bienvenida y navegación.
2. **Formulario (`/formulario`):** Sección para la captura y registro de nuevos usuarios.
3. **Lista (`/lista`):** Tabla interactiva para la consulta y gestión de usuarios.

---

## Requisitos Previos

Asegúrate de tener instalado en tu sistema:
- **Node.js** 
- **Angular CLI** instalado globalmente:
  ```bash
  npm install --global @angular/cli
  ```
